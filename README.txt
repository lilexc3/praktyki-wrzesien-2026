EGZAMIN - ARCHIWUM ZSM3
======================

Lokalne archiwum egzaminow zawodowych.
Wymagania: Apache, PHP 8.1+, MySQL lub MariaDB.

Instalacja: skopiuj katalog do htdocs, zaimportuj database/baza.sql
i ustaw polaczenie w config/database.php. Importuj do nowej bazy.

Wspolne funkcje i przygotowane zapytania SQL: includes/functions.php.
